# Hub de Leitura - Testes de API

Projeto desenvolvido durante o curso de Qualidade de Software da EBAC.

## Objetivo

Validar a funcionalidade de Catálogo de Livros da API Hub de Leitura utilizando o Postman.

## Tecnologias

- Postman
- REST API
- JSON
- GitHub

## Cenários Implementados

### Cenários Positivos

- Listar livros
- Buscar livro por ID
- Criar livro
- Atualizar livro
- Excluir livro

### Cenários Negativos

- Buscar livro inexistente
- Criar livro com dados inválidos

## Arquivos

- `Hub de Leitura.postman_collection.json`
- `Localhost.postman_environment.json`

## Execução

1. Importar a Collection no Postman
2. Importar o Environment
3. Executar a API localmente
4. Rodar a Collection
